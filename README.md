# 面值 FACE VALUE · 男生颜值实验室

一个完全本地运行的中文照片测评网页。它从单人照片中提取人脸关键点，按固定规则生成一个 0–100 的娱乐参考分，并给出四项分数、画面亮点和拍照建议。

## 启动

Windows 上双击 `start.bat`。程序会启动一个只监听本机的服务，并打开：

`http://127.0.0.1:4173/`

也可以在此目录打开终端运行 `node server.mjs`，或使用 `npm start`。

## GitHub Pages

仓库已包含 `.github/workflows/pages.yml` 和 `.nojekyll`。将 `main` 分支推送到 GitHub 后，在仓库的 Settings → Pages 中选择 GitHub Actions，工作流会自动发布静态站点。GitHub Pages 只负责托管网页和模型文件，不运行 `server.mjs`。

网页中的“我的设备”模式可以直接在 GitHub Pages 上使用：每位访问者的浏览器独立运行人脸模型。

“主机电脑”模式默认关闭。运行 `start-host.bat` 会启动主机控制台（`http://127.0.0.1:4174/host.html`）和本机 API（`127.0.0.1:4175`）。它不能通过 GitHub Pages 直接访问某台电脑的 `localhost`，需要你另外使用 HTTPS 隧道把 **4175 端口**映射到公网，再把稳定的 HTTPS API 地址（不带 `/api/analyze`）写入 `config.js` 的 `hostEndpoint`，然后提交到 GitHub Pages。访问者在页面中输入你私下提供的临时访问码，照片才会发送到主机服务。

主机服务已经加入严格的来源白名单、访问码校验、请求体上限、每分钟限流、最多 2 个排队任务、单任务超时和内存清理。主机页面必须保持打开且模型已就绪；电脑休眠或主机页面关闭后，访客应切回“我的设备”。

不要把本机端口直接暴露到公网，也不要把长期密钥写入前端代码。主机电脑必须持续在线；主机不可用时，访问者应切回“我的设备”模式。

## 说明

- 照片只在浏览器内存中处理，不会上传到网络；刷新页面或移除照片即可清除当前结果。
- 评分由画面对称、五官比例参考、照片清晰度和光线表现组成，权重为 35% / 25% / 20% / 20%。
- 这是拍摄条件与程序模板的娱乐参考，不代表客观颜值、个人价值或他人的审美。
- 页面自带示例照片，来源和许可说明见 `assets/README.md`。
- 人脸模型与运行库已随程序附带，首次启动不需要下载 CDN 资源。
